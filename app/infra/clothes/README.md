# Garment models (plan 19)

3D clothes from the MakeHuman Community asset packs (Shirts 01, Shirts 02, Pants 01, Skirts 01, Dress 01, Shoes 01;
https://static.makehumancommunity.org/assets/assetpacks.html). CC0, plus four CC-BY 4.0 tops from Shirts 02
(attribution required: keep the table below; checked against each pack's catalog; files whose header said AGPL
were left out). Kept: the `.mhclo` binding, the `.obj` mesh, the `.mhmat`
material and its diffuse texture shrunk to 1024 px (the renderer only uses it for shading detail; the
colour comes from the user's photo). Normal/spec/height maps were dropped.
